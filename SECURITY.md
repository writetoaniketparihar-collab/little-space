# Security policy

## Report privately

Please do not report security vulnerabilities in public issues or attach private notes, credentials or customer information.

Email [hello@littlespace.pro](mailto:hello@littlespace.pro) with the subject "Little Space security report". You can also use GitHub's private vulnerability reporting if available under this repository's Security tab.

Include the app version, macOS version, a description of the issue and steps using fictional data. Do not send an exploit against another person's device or data. Please allow time to investigate and coordinate a fix before publishing details. No response-time guarantee or paid bounty is offered.

## Versions

Security fixes are intended for the current release. Older releases do not have a separate security-maintenance commitment. Use the official customer portal to obtain updates.

## Repository scope

This repository contains public documentation and issue templates. Application source code, build systems, signing credentials, customer data and paid installers are maintained outside it. No GitHub Actions workflows or deployment credentials are required for this repository.

Apple signing and notarization checks are documented in [downloads and installer verification](docs/DOWNLOADS.md). They do not replace vulnerability reporting or ongoing maintenance.
